In case you /might/ be aware, I just created two new brances--developer-builds and release-builds.

Now, you might be wondering... well, what's the difference?

Well, besides just being two different names, there's actually a difference in file/folder structure for each release.

There's also a /slight/ difference in how the versions are labeled within the code themselves.

For developer versions:
  The files are crammed into one whole folder.
  The window and is labeled "(Developer)".
  The version number is not labeled by default.
For release versions:
  The files are more organized, making it easier for finding specific files.
  The window and version number are labeled "(Release)".

One more thing I should point out is the fact that both versions will still show a little thing called "DeveloperVersion". That only means that there isn't as much content/fixes as there would be in the actual version release.
